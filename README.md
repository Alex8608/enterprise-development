# Разработка корпоративных приложений

## Цель
Реализация сервисно-ориентированного приложения для управления авиакомпанией.

---

## Лабораторная работа 1 - "Классы"

### Доменная модель
В рамках первой лабораторной работы реализована доменная модель авиакомпании. В базе данных хранятся сведения об авиарейсах, пассажирах, билетах, моделях самолетов и их семействах.

#### Классы сущностей

**AircraftFamily** - семейство самолетов:
- Идентификатор
- Название семейства
- Производитель

**AircraftModel** - модель самолета:
- Идентификатор
- Название модели
- Дальность полета (км)
- Пассажировместимость
- Грузовместимость (тонны)
- Ссылка на семейство

**Flight** - авиарейс:
- Идентификатор
- Шифр рейса
- Пункт отправления
- Пункт прибытия
- Дата и время отправления
- Дата и время прибытия
- Время в пути
- Ссылка на модель самолета

**Passenger** - пассажир:
- Идентификатор
- Номер паспорта
- ФИО
- Дата рождения

**Ticket** - билет:
- Идентификатор
- Номер места
- Наличие ручной клади
- Вес багажа (кг)
- Ссылки на рейс и пассажира

### Тестовые данные
В рамках лабораторной работы подготовлены тестовые данные:
- **10 семейств самолетов** от производителей Airbus, Boeing, Bombardier, Embraer
- **10 моделей самолетов** с полными техническими характеристиками
- **10 рейсов** по международным маршрутам
- **10 пассажиров** с валидными паспортными данными
- **24 билета** с различными сценариями багажа

## Unit-тесты

### FlightQueryTests
Юнит-тесты с использованием fixture для подготовки тестовых данных:

#### 1. **Top5FlightsByPassengerCount**
Вывести топ 5 авиарейсов по количеству перевезенных пассажиров.

**Логика теста:**
- Группировка билетов по рейсам
- Подсчет количества пассажиров на каждом рейсе
- Сортировка по убыванию количества пассажиров
- Выбор первых 5 записей

#### 2. **FlightsWithMinimalDuration**
Вывести список рейсов с минимальным временем в пути.

**Логика теста:**
- Нахождение минимальной продолжительности среди всех рейсов
- Фильтрация рейсов с минимальной продолжительностью

#### 3. **PassengersWithNoBaggageOrderedByName**
Вывести сведения обо всех пассажирах, летящих выбранным рейсом, вес багажа которых равен нулю, упорядочить по ФИО.

**Логика теста:**
- Фильтрация билетов по рейсу и нулевому весу багажа
- Выбор пассажиров из отфильтрованных билетов
- Сортировка по полному имени в алфавитном порядке

#### 4. **FlightsByAircraftModelInPeriod**
Вывести сводную информацию обо всех полетах самолетов выбранной модели в указанный период времени.

**Логика теста:**
- Фильтрация рейсов по модели самолета
- Фильтрация по временному периоду
- Возврат всех соответствующих рейсов

#### 5. **FlightsByDepartureAndArrival**
Вывести сведения о всех авиарейсах, вылетевших из указанного пункта отправления в указанный пункт прибытия.

**Логика теста:**
- Фильтрация рейсов по городу отправления
- Фильтрация по городу прибытия
- Возврат всех рейсов на указанном маршруте
